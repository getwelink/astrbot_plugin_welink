# astrbot_plugin_welink

把一个**微信个人号**接成 AstrBot 的消息平台。装上之后，AstrBot 的平台列表里会多出一个 `welink`，和 telegram、discord、企业微信这些并列。

**轮询取消息，不需要公网地址。** 家里的树莓派、NAS、docker 容器都能直接用，不用做端口映射，也不用买域名。

---

## 装

把这个目录放进 AstrBot 的 `data/plugins/`：

```bash
cd data/plugins
git clone https://github.com/getwelink/astrbot_plugin_welink
```

重启 AstrBot，或者在插件管理里点重载。

## 配

到 WebUI 的「平台适配器」里新增一个，类型选 `welink`，填两项：

| 配置 | 说明 |
| --- | --- |
| `base_url` | WeLink 服务地址，例如 `https://你的地址`（会自动补 `/v1`） |
| `api_key` | 控制台里的 API Key，形如 `key_xxx` |
| `account_id` | 用哪个微信实例。**留空会自动选一个在线的** |
| `poll_interval` | 几秒拉一次，默认 3 |
| `poll_limit` | 一次最多拉几条，默认 100，上限 200 |
| `download_image` | 收到图片时换成可下载地址交给模型，默认开 |
| `group_reply_needs_at` | 群里只回复 @ 了自己的消息，默认开 |

没有 Key 的话，[到这里免费领一个](https://github.com/getwelink/weLink#怎么用起来免费)。

## 能做什么

**收**：私聊和群聊的文字；图片会转成地址交给模型（视觉模型可以直接看）；语音、视频、文件、表情、链接、小程序卡片会以 `[语音]` 这样的标签送进去，让模型知道来了东西而不是空一轮。

**发**：文字、图片、语音、文件。群里 `@` 某人会真的 `@` 到。

**主动发**：支持 `send_by_session`，插件和定时任务可以直接往某个会话推消息。

## 几个要注意的

**群里默认只回 @。** 不然一个几百人的群会把你的 token 烧光。想让它什么都回，把 `group_reply_needs_at` 关掉。

**自己发的消息不会触发机器人。** 你在手机上发的消息也会从事件流里过来，插件靠事件里的 `self` 字段把它们丢掉，否则机器人会自己跟自己聊起来。

**重启不会重放历史。** 第一次拉取从启动那一刻算起。

**发本地文件需要 `callback_api_base`。** WeLink 是拿一个地址自己去下载，不是你上传给它。所以 AI 生成的图片要先经过 AstrBot 自带的文件服务对外暴露 —— 在 AstrBot 配置里设好 `callback_api_base`，而且这个地址得是 **WeLink 服务端能访问到的**。已经是 http(s) 地址的图片不受影响，直接就发了。

**空轮询不推进游标。** 这条看着像实现细节，但它决定会不会丢消息：没拉到东西就等于什么都没确认，游标原地不动，下一轮重新问。

## 风险

微信的用户协议不允许非官方客户端，这类方案都有账号被限制的风险。触发风控的通常不是"用了接口"本身，而是**行为像机器**：秒回、高频、批量加好友、群发广告。用自己的号、做自己的事、控制频率。重要的号别拿来试。
