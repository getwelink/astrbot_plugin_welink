# astrbot_plugin_welink

AstrBot 的微信个人号适配器。安装后，AstrBot 的「平台适配器」中会多出一个 `welink` 类型，可以把一个微信个人号接入 AstrBot，用法和 Telegram、Discord、企业微信等平台一样。

插件通过轮询获取消息，不需要公网地址。家里的电脑、NAS 或 Docker 容器都可以直接运行，不用做端口映射，也不用准备域名。

## 安装

需要 AstrBot 4.14.0 或以上版本。下面两种方式任选一种。

**方式一：在 WebUI 中安装**

打开「插件」→「安装」→「从链接安装」，填入：

```
https://github.com/getwelink/astrbot_plugin_welink
```

**方式二：用命令行安装**

```bash
cd data/plugins
git clone https://github.com/getwelink/astrbot_plugin_welink
```

安装后重启 AstrBot，或在插件管理中点击「重载」。

## 配置

在 WebUI 的「平台适配器」中新增一个适配器，类型选择 `welink`。必填的只有 `base_url` 和 `api_key`，其他配置保持默认即可。

| 配置项 | 说明 |
| --- | --- |
| `base_url` | WeLink 服务地址，例如 `https://你的地址`，末尾的 `/v1` 可以不写 |
| `api_key` | 在 WeLink 控制台创建的 API Key，形如 `key_xxx` |
| `account_id` | 要接入的微信实例。留空时会自动选择一个在线的实例 |
| `poll_interval` | 拉取消息的间隔，单位为秒，默认 3 |
| `poll_limit` | 每次最多拉取的消息数，默认 100，最大 200 |
| `download_image` | 收到图片时，是否转成下载地址交给模型，默认开启 |
| `group_reply_needs_at` | 群聊中是否只处理 @ 机器人或以唤醒前缀开头的消息，默认开启 |
| `loop_guard_per_minute` | 同一个会话每分钟最多触发机器人的次数，超过后暂停处理该会话 3 分钟。默认 12，填 0 表示不限制 |

还没有 API Key 的话，可以[在这里申请](https://github.com/getwelink/weLink#怎么用起来免费)。

## 功能

- **接收消息**：支持私聊和群聊。文字直接交给机器人；图片会转成下载地址，视觉模型可以直接识别；语音、视频、文件、表情、链接和小程序会以 `[语音]` 这样的标签交给机器人，让它知道收到了什么。
- **发送消息**：支持文字、图片、语音和文件。在群里 @ 某个人时，对方会收到真正的 @ 提醒。
- **主动发送**：支持 `send_by_session`，其他插件和定时任务可以直接向指定会话发送消息。

## 使用说明

**群聊中，机器人只处理两种消息**：@ 了机器人的消息，以及以 AstrBot 唤醒前缀开头的消息（默认是 `/`，如果在 AstrBot 设置中改过，以设置为准）。例如 `@机器人 /help` 和直接发送 `/help` 都会执行命令，`@机器人 今天天气怎么样` 会交给大模型回答。群里的其他聊天不会处理，避免在人多的群里消耗大量 token。如果希望机器人处理所有群消息，可以关闭 `group_reply_needs_at`。

**自己发出的消息不会触发机器人。** 在手机上用这个微信号发出的消息也会同步过来，插件会自动忽略，避免机器人回复自己。

**重启后不会处理历史消息。** 插件只处理启动之后收到的消息。

**可以直接发送本地文件。** AI 生成的图片或本地磁盘上的文件，插件会先上传再发送，不需要配置 `callback_api_base`，也不需要公网地址。已经是 http(s) 链接的图片会直接发送。

**同一条消息只处理一次。** 即使同一条消息被重复拉取，机器人也只会回复一次。

**不处理系统消息和自动回复账号。** 来自「微信团队」等微信系统账号和公众号（`gh_` 开头）的消息，以及进群退群提示、撤回通知、好友申请，都不会交给机器人。比如「微信团队」会对收到的任何消息自动回复"如果遇到问题，可轻触此处反馈给我"，如果机器人去回复它，双方就会一直来回发送。

**防止和其他自动回复互相刷屏。** 如果对方也开着自动回复，两个机器人可能会一直互相回复。插件会统计每个会话一分钟内触发机器人的次数，超过 `loop_guard_per_minute`（默认 12 次）后暂停处理该会话 3 分钟，并在日志中记录一条提醒。正常聊天一般不会达到这个频率。

## 升级

在插件目录执行：

```bash
cd data/plugins/astrbot_plugin_welink
git pull
```

然后在插件管理中点击「重载」，或重启 AstrBot。配置不需要修改。

## 风险提示

微信用户协议不允许使用非官方客户端，这类工具都存在账号被限制的风险。容易触发风控的通常是明显像机器的行为，比如秒回、高频发送、批量加好友、群发广告。建议使用自己的账号，控制发送频率，重要的账号不要用来测试。
